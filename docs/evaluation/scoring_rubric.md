# Scoring Rubric
**Version**: v1.1 (FROZEN FOR CALIBRATION) | **Date**: 2026-09-01

## Purpose

This rubric defines the evaluation dimensions used in both the LLM Judge (Phase B) and the Human Calibration (Phase C). Both evaluators must use the same rubric to ensure comparable scores.

---

## Scoring Dimensions

Score each dimension **independently** for Legacy and V2. Do not compare them at this stage.

| Dimension | Abbrev | Scale | Description |
|:---|:---|:---|:---|
| Definition Accuracy | `DEF` | 1–5 | Is the definition lexically and factually correct? |
| Sense Quality | `SEN` | 1–5 | Are the senses distinct, accurate, necessary, and comprehensive? |
| Arabic Learner Quality | `ARA` | 1–5 | Is the Arabic natural, clear, low cognitive load, and audience-appropriate? |
| Mnemonic Validity | `MNE` | 0–5 | Is the mnemonic a genuine retrieval hook or just a repeated definition? |
| Pronunciation | `PRN` | 1–5 | Is the IPA transcription accurate for US English? |

---

## Score Descriptions

### General Scale (DEF, PRN)
- **5** — Excellent: No errors. Fully accurate.
- **4** — Good: Minor imprecisions.
- **3** — Adequate: Correct at a basic level.
- **2** — Weak: Errors that could confuse.
- **1** — Poor: Factually wrong.

### Mnemonic Validity (`MNE`)
- **5** — Highly memorable, natural learner-oriented hook.
- **4** — Strong phonetic/semantic imagery.
- **3** — Clear memorable association.
- **2** — Simple but usable association.
- **1** — Weak association, unlikely to aid recall.
- **0** — Absent / Just a definition paraphrase / Not a mnemonic.

### Arabic Learner Quality (`ARA`)
- **5** — Warm, learner-friendly, low cognitive load, highly natural (pedagogical gold).
- **4** — Clear and accurate, but slightly formal.
- **3** — Standard academic translation, high cognitive load but correct.
- **2** — Awkward phrasing or overly complex.
- **1** — Unnatural or incomprehensible Arabic.

### Sense Quality (`SEN`)
- **5** — Perfect coverage; senses are distinct, necessary, and non-overlapping.
- **4** — Good coverage, but slightly redundant or missing a minor usage.
- **3** — Adequate coverage, but either misses a key sense or artificially splits one meaning.
- **2** — Poor distinctness; bloated senses or critical missing usages.
- **1** — Completely inaccurate or hallucinated senses.

## Phase 1 Scope

Only score fields that Phase 1 is responsible for:

| Field | Evaluable in Phase 1? |
|:---|:---|
| `phonetic_us` | ✅ Yes |
| `phonetic_uk` | ✅ Yes (note: V2 may omit for some words — see known issue) |
| `phonetic_ar` | ✅ Yes |
| `definition_en` | ✅ Yes (per sense) |
| `definition_ar` | ✅ Yes (per sense) |
| `mnemonic_ar` | ✅ Yes |
| `sense_count` | ✅ Yes (how many senses) |
| `examples` | ❌ Not generated by Phase 1 |
| `collocations` | ❌ Not generated by Phase 1 |
| `synonyms` | ❌ Not generated by Phase 1 |
| `translations` | ❌ Not generated by Phase 1 |

Do not penalize V2 for absent Phase 2–4 fields.

## Comparison Verdict

After scoring Legacy and V2 independently, assign a comparison verdict:

### Winner
```
legacy              V2 clearly worse or no improvement
v2                  V2 clearly better
tie                 Roughly equal quality
insufficient_evidence   Not enough data to decide (e.g., field missing in both)
```

### Improvement Level
```
major       Significant quality difference (e.g., accuracy, completeness, naturalness)
minor       Small improvement noticeable but not critical
none        No meaningful difference
regression  V2 is worse than Legacy
```

---

## LLM Judge Instructions

The LLM Judge must:

1. **Score Legacy independently** across all applicable dimensions.
2. **Score V2 independently** across all applicable dimensions.
3. **Identify the winner** per field and overall.
4. **Flag any Phase 1 scope violations** (e.g., V2 hallucinating fields it should not generate).
5. **Return a structured JSON verdict** conforming to the Judge schema.

The LLM Judge must **not**:
- Assume the newer output is better.
- Skip evaluation for "obvious" cases without reasoning.
- Assign a winner without evidence in the content.

---

## Human Reviewer Instructions

The human reviewer should:

1. Read the Legacy entry and score it on each dimension (1–5).
2. Read the V2 entry and score it on each dimension (1–5).
3. Assign a winner per field and overall.
4. Note any specific reasoning for non-obvious decisions.
5. Submit scores **before** seeing the LLM Judge verdict.

Only after both scores are submitted should the comparison be revealed.
