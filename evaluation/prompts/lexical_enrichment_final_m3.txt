# 10. MNEMONIC_AR

mnemonic_ar is OPTIONAL.

Its purpose is retrieval, not explanation.

Default = null.

Return a mnemonic when it passes BOTH tests:

Counterfactual Test:
Could this hook help a learner recognize or reconstruct the target meaning after forgetting the word?

Novelty Test:
Does it add a memorable cue that is not simply the translation, definition, root, suffix, or obvious related word?

A strong hook that passes both tests is the goal. Whether a hook exists depends on the word itself, not on how cautious you are. For most concrete or imageable words a workable hook can usually be found.

Null is a deliberate last resort, not a default to fall back on whenever a hook is not immediately obvious. Only return null when every candidate hook fails one of the two tests.

Especially favor strong hooks of these kinds:

- a clear sound or spelling link, including a genuine resemblance to a familiar Arabic word or common word in the learner's world;
- a memorable historical or cultural origin (for example "paper" from "papyrus");
- a striking mental image or everyday-life association;
- a contrast that fixes a distinct meaning (for example an opposite or a near-confusable pair).

A weak or forced hook is still rejected. Return null when:

- it merely translates the word;
- it repeats the definition;
- it exposes only an obvious morphological relationship such as "garden" + "-er";
- it uses a weak or far-fetched sound resemblance;
- it is generic;
- it requires a long explanation;
- it is less memorable than simply learning the word.

Distinguish a weak sound resemblance from a genuinely strong one. "loud"/"cloud" and "perceive"/"receive" are strong because the shared sound maps to a concrete mental link; a random rhyming word you cannot tie to meaning is weak.

Phonetic-hook guard: a sound-based hook is allowed only when the anchor is a real word whose pronunciation genuinely overlaps the target's stressed syllable(s) AND the link to meaning is explicit. Never build a hook on a misleading fragment — an Arabic syllable or foreign word that merely resembles part of the target's spelling while carrying an unrelated meaning. A confusing resemblance is worse than no hook: return null.

Etymology discipline: a factual-sounding derivation claim ("X comes from Y", "both share the root Z") is allowed only when you are confident it is correct. When uncertain, use transparent associative framing instead ("think of X", "notice the part Y") — never present a guess as a fact.

Morphology-hook availability: for Latinate or Greek-derived academic words, a clean morphological decomposition (prefix + root + suffix, each with a real meaning) counts as an available hook. Do not return null when such a decomposition exists and passes both tests above; null requires that every candidate hook — including the morphological one — fails a test.

One strong hook is better than several weak hooks.

- English words must be enclosed in double quotes;
- no parentheses;
- no square brackets.

Secondary-sense mnemonics should normally be null unless independently strong.
